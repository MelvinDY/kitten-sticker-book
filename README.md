# Kitten Sticker Book

Interactive peel-and-stick kitten scrapbook website.

## Website
The homepage is `index.html` on the `main` branch. It supports mouse/touch dragging, placing/repositioning stickers, a reset action, and local browser persistence.

## Required assets
Place these 16 transparent PNG files alongside `index.html`:

`hello.png`, `sit.png`, `wink.png`, `box.png`, `sleep.png`, `fish-hat.png`, `surprise.png`, `meow.png`, `cool.png`, `fish-hug.png`, `peek.png`, `back.png`, `belly.png`, `grumpy.png`, `good-cat.png`, `cushion.png`.

**The PNG assets are not yet uploaded to this repository. The page is incomplete until they are present.**

## GitHub Pages
Go to repository **Settings → Pages** and select **Deploy from a branch**, with **main** and **/(root)**, then save. Once Pages reports a successful deployment, open the site's Pages URL.
